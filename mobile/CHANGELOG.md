# CineTracker 1.1.2

- Includes Send feedback in Settings, with Instagram and Telegram choices.
- Open Devanarayanan's profile/chat, then type and send a bug report or suggestion.
- Publishes the correct feedback-enabled APK in a new version. The existing
  1.1.1 release currently contains a 1.1.0 APK and is not eligible for app updates.
- Existing social links, dark mode, watchlist, and collection refresh remain available.

## Installing this test build

In CineTracker 1.1.0 or later, open Settings > Check for updates > Download update.
Alternatively, download CineTracker-1.1.2-debug.apk from this release and open it on Android.

This is a development-signed test build. Android may require uninstalling the
previous test build because debug signing keys differ. Uninstalling removes
local watchlists and settings. A persistent private release-signing key is
required before promising in-place production updates.

Update checks do not silently install APKs or run while the app is closed.
