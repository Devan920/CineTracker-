# CineTracker 1.1.1

- Added Send feedback in Settings.
- Choose Instagram or Telegram to message Devanarayanan with a bug report or suggestion.
- Feedback opens the provided profile/chat; the user types and sends the message.
- Existing social links, app update checks, dark mode and collection refresh remain available.

## Installing this test build

CineTracker 1.1.0 users can open Settings > Check for updates > Download update.
Alternatively, download the APK from this release and open it on Android.

This is a development-signed test build. Android may require uninstalling the
previous test build because debug signing keys differ. Uninstalling removes
local watchlists and settings. A persistent private release-signing key is
required before promising in-place production updates.

Update checks do not silently install APKs or run while the app is closed.
