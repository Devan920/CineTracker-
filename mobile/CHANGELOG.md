## Availability limitation

The app does not display confirmed film screenings, showtimes or live free-seat counts. It has no connected booking inventory provider. Nearby cinemas are mapped venue locations and are labelled as unverified for the chosen film. Capacity is never presented as vacant seats. Direct live inventory requires an authorized cinema/booking-provider integration.

## Installation

The in-app checker downloads the Android test APK, which the user opens to install. Android may require the user to confirm installation. This development-signed build may require uninstalling a previous test build if its debug signing key differs. Uninstalling removes local watchlists/settings.
